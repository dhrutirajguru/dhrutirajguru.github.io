# TalentSync UI Prototype

Frontend-only interactive prototype for SIH 2026.

## Run
Open `index.html` in any modern browser.

## Included
- Student, Academician, Industry and Institution roles
- Role-based dashboards and navigation
- Skill assessment and skill mapping
- Career readiness and recommendations
- Internship/job search and dummy applications
- Application tracking
- Learning programs and portfolio
- Industry candidate matching and opportunity posting
- Institution analytics
- Notifications and responsive layout
- No backend required; all data is dummy and stored in memory
